# SplatCat Agent Instructions & Guidelines

## Agent skills

### Issue tracker

GitHub Issues via `gh` CLI. External PRs are not a triage request surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical 5-role labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (`CONTEXT.md` + `docs/adr/` at root). See `docs/agents/domain.md`.
